# Tiny Tides

A polished 2D indie fishing game designed to run entirely in a web browser. Hosted on GitHub Pages.

## Features
- **Ocean-themed Pixel Art:** A cozy and immersive aesthetic.
- **Open Ocean Exploration:** Discover different fishing spots, secrets, and NPCs.
- **Story Mode & Free Roam:** Two distinct ways to play.
- **Fishing Minigame:** Dive underwater and wrestle with different fish types.
- **Upgrades & Economy:** Catch fish, sell them, and upgrade your gear in the shop.
- **Persistent Progression:** Save and load your game directly in the browser (LocalStorage).

## How to Run Locally
Since the game is a static web application built with HTML, CSS, and Vanilla JavaScript, there are no server-side requirements. You can run it locally by either:
1. Opening `index.html` directly in your web browser.
2. Running a local HTTP server in the root directory (e.g. `npx serve` or `python -m http.server`).

## Deployment
This project is structured to be deployed directly to GitHub Pages. Simply push this repository to GitHub and enable GitHub Pages on the `main` branch.
